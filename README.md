# SolaceAI 💚

SolaceAI is a wellness application designed to support users in maintaining their mental well-being through mood tracking, breathing exercises, journaling, and AI-powered conversations.

## Features

- **Mood Tracking:** Record and track daily moods.
- **AI Chat:** Interact with an AI wellness assistant.
- **Breathing Exercises:** Practice guided breathing exercises.
- **Journal:** Write, save, and manage personal journal entries.
- **Mood History:** Review previously recorded moods.
- **Daily Reminders:** Receive wellness reminders.

## Tech Stack

- React Native
- Expo
- JavaScript
- Node.js
- MongoDB / API integration (if configured)

## Project Structure

- `SolaceAI/` – Mobile application
- `backend/` – Backend application

## Getting Started

Clone the repository:

```bash
git clone https://github.com/jyoshna-7/SolaceAI.git
```

Install frontend dependencies:

```bash
cd SolaceAI/SolaceAI
npm install
```

Start the Expo application:

```bash
npx expo start
```
